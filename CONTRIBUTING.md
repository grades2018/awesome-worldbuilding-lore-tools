# Contributing

Thanks for helping improve this list.

- One tool per pull request, added to the section where it fits best.
- Use the official site link and a short, neutral one-line description.
- Tools must be useful to authors or storytellers who build worlds, lore, and continuous settings, and must be actively maintained.
- Format: `- [Name](https://link) - Description.`
- No affiliate or tracking links.

If this list is useful to you, a star helps other writers find it.
